# Station Base v1 — checkpoints

Исходная точка: b0c901161ed97f7964b5921fbdc3f3ace94a498d. Ветка feature/station-base-v1. Все параметры относятся к технической совместимости v106, а не к реальным размерам Малиновки.

## Этап 1. Модульные контракты

Созданы StationDefinition, TrainCompatibilityProfile, TrackModule, PlatformModule, TrainStopModule, TunnelConnector, CollisionModule, PassengerStationContract, DecorationInterface и Validation. Геометрические значения централизованы в data/station-base/v106.js. Выход модулей — данные, независимые от Three.js.

Проверка: node --test tests/station-base.test.js — 6/6. Включены отрицательные сценарии: слишком короткая платформа, неподдерживаемая конфигурация, неправильная высота рельса/двери, несовпадающий порт. Проверено сохранение мировых координат для всех 16 дверей при смене пространства.

Это промежуточный checkpoint: 3D-просмотрщик и проверка фактических mesh ещё не реализованы. Обход колёс должен читать batchedParts, а не исчезающие userData.wheel. Данные пассажиров остаются контрактом, без PassengerSystem. Ни один существующий игровой/поездной файл не изменён.

## Этап 2. Двухпутный просмотрщик и фактические mesh

Создана station-base.html, свободная камера, исходный live v106 через неизменный загрузчик, независимый clone transform graph второго статичного v106, переключатель его видимости. Геометрия и материалы клона разделяют исходные ресурсы; дверные узлы независимы. Центральный профиль: railHead=0, train root +0,220, platform top=1,1805, edge offset=1,370. Ширина демо 8 м: ось второго пути X=−(8+2×1,370)=−10,740 м. Две остановки, 32 привязки по 16 на путь, независимые ожидание/посадка/высадка, четыре TunnelPort. Контракт состояний EMPTY/APPROACHING/STOPPED/BOARDING/DEPARTING; второй поезд в просмотрщике только статичный.

Проверки: 10/10 unit/contract tests; CPU-исполнение исходных построителей на Three r160: 50 положительных сценариев и 4 отрицательных. Обе стороны и направления; 32 колеса на каждом составе, все 16 обслуживаемых проёмов, реальные рельсовые mesh и плита, объёмная полоса, отсутствие пересечений между составами. SHA256 исходных BufferGeometry до/после одинаков. Результаты: test-results/station-base/geometry.json.

Ограничение браузерного QA: cloud Chrome не создаёт WebGL-контекст (GL_VENDOR/GL_RENDERER Disabled). Это не визуальная приёмка; скриншоты успешного 3D пока не получены. Добавлен изолированный CI acceptance workflow с Chromium/SwiftShader, проверкой точного three@0.160.1 и сохранением отчётов/скриншотов только в feature/station-base-v1. Основные deploy workflows и gh-pages не изменены. Пока CI не завершён, рендер не объявляется подтверждённым.
