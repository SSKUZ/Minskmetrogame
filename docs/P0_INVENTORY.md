- `docs/station-base/README.md`: 2 пути, островная платформа, 2 состава v106, второй статичен; 16 дверных ID на путь; пассажирские зоны **без подключённой системы пассажиров**. Размеры технической платформы 105×8 м — не обмер Малиновки.
- `preview/WAGON_PROGRESS.md`: v106 построен из 81-717 / 81-714 / 81-714 / 81-717, использует повторно применяемые сборщики и Three.js BufferGeometry/materials; это не доказательство наличия экспортируемого FBX/GLB.
- `docs/cab/PROGRESS-R2.md`: кабина процедурная; отчёт указывает 182 меша, 145504 треугольника, 49 материалов, 40 органов управления; 0.53 FPS на CPU SwiftShader не соответствует FPS Android.
- `docs/passengers/PROGRESS.md`: ранний checkpoint указывает 12 GLB-профилей с 6 анимациями и 6/7 пройденных тестов; актуальный архив нужно проверять отдельно.
- Относительные списки файлов получены через сравнение веток с `main`; SHA **головных коммитов** веток пока не зафиксированы, поэтому P0 не закрыт.
