## Б. Рекомендуемые проектные значения — требуют утверждения

| Параметр | Рекомендация | Обоснование / область |
|---|---:|---|
| Ноль высот | Головка рельса Y=0 | Общая опора пути, поезда и соединительных портов |
| Перенос исходного состава | (0; +0,220; +9,603) | Номинальный передний торец Z=0; неизменная геометрия |
| Рельсовый профиль первой совместимой версии | Центры X=±0,900; ширина 0,120; высота 0,160; центр Y=−0,080 | Совместимость с v106; специальное имя v106-compat-box-1, без заявления реального профиля |
| Порог / платформа | Y=1,1805 / 1,1805 | Номинально без ступени относительно основного пола |
| Край обслуживаемой платформы | X=−1,370 | 33 мм до измеренного габарита полосы |
| Зазор до кузова / порога | 0,033 / 0,0695 | Разница 36,5 мм объясняется утопленным порогом |
| Пробный бюджет отклонений | ±0,010 X; ±0,005 Y | Проверка запаса, не модель подвески; после X остаётся 23 мм |
| Допуск сравнения mesh | 0,001 | После бюджета остаётся 22 мм консервативного расчётного запаса |
| Проход пассажиров: halfWidth | 0,590 | Полоса 1,180 внутри 1,203 проекции створок; косяки/капсулы отдельно |
| Толщина плиты техдемо | 0,200 | Проверена вся полоса, но глубина реальной конструкции индивидуальна |
| Зона запрета для архитектуры техдемо | abs(X)<1,650; 0≤Y≤4,020 | Консервативная AABB + около 0,10 м; стык с краем платформы имеет отдельную высотную маску |
| Длина/ширина универсального каркаса | Параметры; фиксированного размера нет | Каждая станция имеет собственные extents и topology |
| Технический тестовый обслуживаемый участок | −3,452…82,676 по Z | Полная AABB состава + по 3 м; длина 86,128. Это минимум выбранного теста при stop error ±0,5, не настоящий план |
| Проверяемая остановка техдемо | front reference Z=0; ошибка ±0,500 | Отдельный сценарий; старый игровой допуск ±3 м пока не меняется |

Минимум 86,128 м не включает настоящие лестницы, тупиковое оборудование и проектные пути эвакуации. Если проверять старый допуск ±3 м, этот запас исчерпан целиком: потребуются большие extents и отдельная приёмка. Длина 105 м и ширина 10 м остаются исследовательскими гипотезами первого отчёта, а не размерами универсального ядра.

## В. Неизвестные реальные размеры

| Параметр | Статус / что требуется |
|---|---|
| Исполнительная длина, ширина, уровень платформы Малиновки | Нужен достоверный план/обмер; учебный проект не подтверждает построенный объект |
| Реальный профиль и колея, рабочие грани колеса/рельса | Нужен первичный профиль/разрез; 1,800 по центрам модели и 1,680 между гранями коробок нельзя называть реальной колеёй |
| Оси путей относительно платформы / стен | Нужна полная размерная цепь, не сочетание противоречивых публикаций |
| Колонны, лестницы и выходы | Нужны координаты, footprints, направления и уровни |
| Потолок, путевые стены, переход к тоннелю | Нужны высотные разрезы и портальные размеры |
| Динамический габарит настоящего/будущего игрового состава | Нет подтверждённых крена, бокового хода и прохождения кривых |
| Нормативно допустимые зазоры и требования реальной инфраструктуры | Не установлены данным исследованием; профиль предназначен для игры |
