# TZ4 route occupancy — work in progress

Stable parent: 8c56b9efffae1ae7a3a9c9a38288f21b9ded21c8.
Branch: feature/passengers-realism-20261028. No merges or geometry changes.

A stop-level demand policy is added to the existing simulation when route length
is supplied. Platforms contain 80–100 people spread over the four-car length.
Only selected intact groups board, normally 30–40 across the whole train, with
balanced per-car quotas. Other people mostly wait. Existing movements, models,
animations, grips and queues are reused.

Targets rise from a light start toward an anchor-derived peak, decline after the
middle and reach zero at the terminus. Initial stand capacity is 92 across four
cars; the future four-door contract fixture allows 112. There is no arbitrary
crowd capacity or hardcoded passenger coordinate. At the terminal every existing
rider is scheduled for animated alighting and boarding is disabled. No rider is
removed from train space to manufacture zero.

The game supplies its actual 15-stop route length. The inspector uses the same
update entry point. Route-less legacy fixtures retain their former behavior.

Initial tests exposed a pre-existing queue pipeline defect: a follower could
occupy the approach bay while the active boarder still had that bay as a pending
route marker. Readiness now requires actual consumption of the marker, and stale
readiness is cleared. A targeted regression is added.

Validation is ongoing. First probes reached 88–112 riders with preserved identities,
but the complete 15-stop terminal test and fresh browser screenshots are not yet
accepted. Ordinary contract deadline is 40 s (target 20–35); the temporary stand
has only eight physical doors, so its functional ceiling is separately 60 s.
Do not present that ceiling as normal target performance or V106 integration.
