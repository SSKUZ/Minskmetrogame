# Постоянный просмотрщик

Адрес: https://sskuz.github.io/Minskmetrogame/metro2/module-viewer/index.html

V48 и V49 — резервные публикации. Обычные обновления направлять только в
`metro2/module-viewer/`. Управление и игровые модули публикационный скрипт не меняет.

Публикация выполняется только по явному заданию пользователя. Автоматической
публикации при коммитах нет. Из рабочей ветки подготовить зависимости существующим
`prepare_module_viewer.py`, выполнить один Web-экспорт Godot 4.3, затем применить
`finalize_viewer_web.py`. В каталоге экспорта должны быть `build-info.json`
с SHA исходного коммита и `SHA256SUMS` для всех остальных файлов.

После получения и проверки актуального HEAD gh-pages:

```sh
python3 metro2/tools/publish_permanent_viewer.py --web-dir /path/to/web-export --expected-pages-head <HEAD>
```

Это создаёт кандидат коммита, не перемещая gh-pages. Для публикации повторить
команду с `--publish`. Требуется `GH_TOKEN` с правом записи в репозиторий.
Скрипт проверяет суммы и сохранность всех файлов вне постоянного каталога,
отказывается от записи при изменившемся HEAD и не использует force push.
После успешного GitHub Pages проверить постоянную ссылку и основные файлы.

PCK запрашивается с уникальным параметром и `cache: no-store`; имя пакета внутри
Godot не меняется. Ссылка на JavaScript содержит хеш загрузчика. Это исключает
повторное использование старого PCK браузером без новых каталогов и без CDN.

Для первой публикации используется готовый V49 через
`--reuse-prefix metro2/module-viewer-v49/`, без нового экспорта.
