## Module contract

Station-local copy of the existing Station Base: island 105 × 10m, platform datum 1.1805m, gauge/track centres and four connection markers retained. Independent station ID and clock state. The structural/art design is new and contains no dependency on the Moscow station. Native opaque StandardMaterial3D textures are used for architecture; closed columns, correct Godot clockwise triangles and solid roof boxes prevent the earlier transparent/black-surface errors.

Signs and frames are wholly within the column openings: clear 3.51m, complete frame 3.23m. Exact whole-station counts and dimensions cannot be surveyed from these photos; twenty columns per row, sign/band cadence and overall heights are scaled estimates. Roof and capital profiles are reconstructed from visible references. Escalators are detailed architectural geometry, not a passenger transport simulation. Hidden upper vestibules are outside this module. The event card is a static isolated owner photograph; other screen faces are black as photographed. Closest front-facing mirror is updated at 6Hz.

`art/owner_sources.json` records original hashes, crop/homography coordinates and all reviewed sources. `tools/akademiya_nauk_photo_v62/build_art.py` reproduces texture crops and outlined bilingual route diagrams (119 highlighted, 115/314 and 116/216 interchanges). Typeface approximation: DejaVu Sans Condensed. Font licence included.

Publication imports resources, generates mipmaps and exports one new native Web station PCK. It adds one catalog/menu entry and updates the existing boot pack. It snapshots the live viewer and preserves every previously published station/train pack. No game, scene, browser, visual or performance tests are run.
