# Звуковая подсистема — ТЗ №54

Вход: пользовательский `metro_audio_review_sorted.zip`, 147 WAV. Оригиналы без изменения — `source_assets/metro_audio_tz54/` вне корня Godot; исходные CSV/JSON/README сохранены. Происхождение и отсутствие установленного разрешения не скрыты; юридическое исследование не проводилось.

`data/audio_catalog.json` и CSV учитывают каждый оригинал, SHA-256, формат, измерения, содержимое, текст, уверенность, события и игровой Ogg. `source_manifest.json` сохраняет пути внутри архива. Неопределённые записи не переименованы под выдуманное оборудование. Дубликаты представлены отдельными строками.

Идентификация автоматическая: полный сигнал, CLAP по всем последовательным 10-секундным окнам, Whisper small и дополнительный large-v3-turbo для ошибочно распознаваемой речи. Прослушивание человеком не выполнялось. Исходные гипотезы сохранены; CLAP cosine не является вероятностью. Расшифровки нормализованы на исходном языке; неясные окончания отмечены. Точная формулировка требует прослушивания. `ready` означает подготовленный ресурс, а не подтверждение точного агрегата или текста.

Распознанные записи подготовлены в Ogg Vorbis q6 с исходными частотой/каналами и без изменения скорости. Три выбранных фона имеют описанный в каталоге шов с перекрытием 60 мс. Оригиналы не обрезаны. Смешанные записи движения не выдаются за изолированные тяговые или тормозные слои.

## Компоненты

- `audio_system.gd`: TrainAudioController, композиция и внешние события.
- `controllers/train_audio_controller.gd`: Traction/Rolling/Brake и фон стоянки — плавные слои по JSON, скорости, ускорению, тяге, тормозу и оборудованию.
- `controllers/rail_joint_audio_controller.gd`: пересечения реальных координат стыков каждой осью, оба направления, сброс при телепортации, координаты модулей и исключение дублей на границах. Случайного таймера нет.
- `controllers/door_audio_controller.gd`: фактическое изменение открытости, разворот движения, завершение; независимые источники у дверей.
- `controllers/cab_audio_controller.gd`: изменения контроллера, тумблеров, удерживаемых сигналов и внешние события кнопок.
- `metro_announcer.gd`: один текст одновременно, синхронные источники по вагонам, ограниченная приоритетная очередь, ручной запуск/повтор/остановка, автоматические события с ID посещения и исключением дублей. Служебные сообщения автоматически не выбираются.
- `controllers/environment_audio_controller.gd`: включение/затухание фона в заданных зонах.
- `audio_event_router.gd`, `sound_bank.gd`: пространственные источники, категории громкости, перспективы кабины/салона/платформы/полёта, ограничение голосов и кэша. На Web — один запрос небольшого импортированного ресурса за кадр, на native — фоновая загрузка с резервным последовательным путём. Вся библиотека в память не загружается.

## Подключение в ТЗ №55

`adapters/v106_audio_adapter.gd` читает свойства V106 базового коммита `61c208bfa826e310d7f4b73764752f5e48788f28`, двери и трансформации существующих тележек/осей. `bind(v106, audio_system)` вызывается владельцем после `consist_ready`. Сейчас адаптер нигде не подключён.

События маршрута — `route_announcement(station_id, phase, direction, visit_id)`. Участок: Уручье — Площадь Ленина, оба направления. Пересадки входят в записи прибытия и не проигрываются второй раз. Площадь Ленина — граница игрового участка, не физическая конечная.

Стыки — `set_track` либо `rail_audio.register_module`. Положение маршрута в базовом адаптере — `-distance`/`-world Z`; для будущих кривых нужен скаляр вдоль пути. Точки PA/оборудования предварительно заданы относительно середины тележек. Питание/окружение передаёт владелец. Существующие проигрыватели не отключаются адаптером; устранение двойного воспроизведения относится к интеграции.

`data/processing_summary.json` перечисляет неподтверждённые привязки. Открытие/закрытие дверей, отдельные стыки, конкретные тормозные/компрессорные и кнопочные события не получают случайные записи. Дополнительные слои включаются данными после подтверждения источника и калибровки, без новой системы управления поездом.

Сцены, autoload, просмотрщик и существующие модули не изменены. Выбран каталог `metro2/audio/`, чтобы независимая заготовка не публиковала неизвестный пакет и не меняла чужие публикации. Штатная сборка подключённой игры — GitHub Actions на этапе интеграции. Локальный импорт/экспорт, игра и тесты не запускались; работоспособность не подтверждена запуском.

JSON сохраняет переносимые ID, события, маршруты, метры, dB, циклы и пространственные параметры. Android APK и Roblox/Luau не создавались. Roblox потребует аудио asset ID и адаптации логики; проверенная совместимость не заявляется.
