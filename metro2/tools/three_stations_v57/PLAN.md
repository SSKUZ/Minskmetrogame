# ТЗ 57 — Восток, Московская, Парк Челюскинцев

Цель: три самостоятельных предварительных модуля Godot 4.3 Web на основе актуального Station Base. База исходников — 206da290facc66e38640b82674a941c4d8bc438c. Новая ветка: feature/metro2-three-stations-v57. Имеющиеся станции, депо, пассажиры и V106 не изменяются.

Порядок работы:
1. Сопоставить открытые фотографии общего зала, пола, названий, потолков и лестниц; учесть модернизацию света.
2. Сохранить внутри каждого каталога локальную техническую копию Station Base. Ось +Z — к центру/Малиновке, -Z — к Уручью. Соседство: Уручье — Борисовский тракт — Восток — Московская — Парк Челюскинцев — Академия наук.
3. Построить три различных архитектурных зала, материалы, светильники, полы, лестницы с площадками и поручнями, торцы и короткие порталы. Четыре действующих цифровых часов и контактные рельсы использовать из существующей инфраструктуры.
4. Нарисовать собственные двуязычные схемы с выделенной текущей станцией, названия и общие указатели выходов. Фотографии не использовать как распространяемые текстуры. Не копировать навигацию Уручья.
5. Сохранить исходники в GitHub до сборки.
6. Выполнить обязательный импорт и экспорт только трёх пакетов. Добавить пункты в существующий просмотрщик, сохранив управление, прежние пакеты и постоянный URL. Опубликовать GitHub Actions, дождаться Pages deploy и остановиться.
7. По будущим фотографиям пользователя уточнить интервалы, форму букв, точное распределение указателей/выходов, светотехнические мелочи и мозаики.

Архитектурные ориентиры:
- Восток: свободный односводчатый зал; белые лепестковые рёбра и световые проёмы, светлый карниз с золотистым названием, красно-коричневый гранит снизу, серый пол со ступенчатыми красными фигурами.
- Московская: два ряда квадратных каннелированных колонн, три пролёта; белый мрамор, чёрный цоколь, низкий кессонированный потолок, продольное освещение, красноватый пол со светлыми рамками. Мраморные московские силуэты и золотистые разреженные буквы. Мозаика пока упрощённая авторская интерпретация.
- Парк Челюскинцев: свободный белый свод с поперечными пазами и центральной продольной нишей; янтарные многорядные люстры-чаши, тёмный гранит снизу, латунные буквенные пластины, каскадные прямоугольники из серого/красного/тёмного гранита пола.

Ограничения: 105×10 м платформы, высоты, количество/интервалы секций и оборудования — рабочие пропорции Station Base и фото, не обмеры. Лестницы смоделированы, неподтверждённые эскалаторы не добавлены. Полные подземные переходы, скрытые помещения и неподтверждённые служебные надписи опущены. Пилон показывает Московскую линию, а не выдаёт неполную схему за полную сеть. Нет маршрута/пассажиров. Геометрия остаётся Mesh/MultiMesh для дальнейшего экспорта Roblox.

Запрет: не запускать игру/сцены, не открывать Web-результат, не делать скриншоты, визуальные/игровые/FPS-тесты. Разрешены только импорт ресурсов и экспорт/публикация; исправлять блокирующие их технические ошибки.
