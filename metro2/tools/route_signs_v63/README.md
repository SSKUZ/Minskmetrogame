# Uruchye route signs V63

Owner reference: Academy of Sciences photograph 7750, plus Uruchye viewer screenshots 8076/8078. Scope: Uruchye only. Vostok is explicitly excluded following the owner's correction.

`build_art.py` creates a single outlined vector image with fifteen equally spaced diagonal station sections, white separators, one yellow current section (124 Uruchye), blue remaining sections and aligned station numbers. It includes bilingual interchange captions, red line 2 at 116/216 (Kupalovskaya) and teal line 3 at 115/314 (Vokzalnaya). All four Uruchye wall diagrams and both faces of each of its four suspended route boards reference this image. Aspect ratios include the complete transfer captions.

The workflow snapshots the published Uruchye PCK and replaces only the architecture script and imported route image. Existing decoration, other modules, train packs, viewer boot and controls are preserved. Import/mipmap generation and native PCK repackaging only; no scene or browser tests.

Artwork is recreated as outlined text using DejaVu Sans Condensed Bold (licence included). Original owner images are not redistributed.
