## Статус достоверности
- **Подтверждено GitHub:** указаны конкретные ветки, коммиты и файлы.
- **Восстановлено по истории обсуждений:** намерения, задания, последовательность решений; возможны пропуски.
- **Не подтверждено:** интеграция или результаты тестирования, для которых нет независимых артефактов.

Никакие переписки ChatGPT автоматически не выгружены. Не помещать в публичный репозиторий личные данные, ключи, токены, частные переписки или чужие материалы без разрешения.

Архивная ветка отделена от игровых веток. Обновлять документы отдельными checkpoint-коммитами, не сливать в main автоматически.
