# Дословный архив переписок — пока не загружен
Этот каталог **не содержит** экспортов чатов ChatGPT. Доступ к истории разговоров не равен возможности автоматически выгрузить все сообщения и вложения.

## Как дополнить архив
1. Пользователь экспортирует данные ChatGPT или предоставляет сохранённые тексты нужных чатов.
2. До публикации удалить личные данные, пароли, токены, конфиденциальные сведения и не относящиеся к игре диалоги.
3. Полные необработанные экспорты предпочтительно хранить в **приватном** репозитории, а не в публичной игровой ветке.
4. В этой ветке можно хранить обезличенные тематические выдержки и ссылки на приватный архив без секретных URL.
5. Добавить индекс: название чата, даты, тема, соответствующая ветка/коммит, статус полноты.

Не объявлять этот архив «полной историей» до импорта исходных переписок.
