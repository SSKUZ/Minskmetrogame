# Хронология проекта (восстановленная)
Даты и этапы ниже основаны на доступных обсуждениях и GitHub; ранние даты могут быть неполными.

1. **Ранний прототип.** Браузерная игра Минского метро: движение, разгон/торможение, двери, станции, камеры, озвучка, остановка с оценкой точности. В обсуждениях фигурировали максимальная скорость 90 км/ч, допуск остановки ±3 м и отдельная логика грубого переезда.
2. **Разделение архитектуры.** Ветки main/develop/testing, feature-модули и рефакторинг. PR №1 «Refactor: modular foundation, camera/door/passenger helpers, regression tests». Исторические регрессионные тесты дверей и наката требовали исправлений; актуальное состояние проверять отдельно.
3. **Вагон 81-717/714.** Многократные визуальные итерации v80–v106: передняя часть, фары, прозрачные окна, кузов, салон, двери, кресло, освещение, наклейки, реклама. В v106 — четырёхвагонный состав. Основная рабочая ветка `integration/consist-v106`.
4. **Кабина машиниста.** Отдельное ТЗ на полную модернизацию панели, приборов, контроллеров, тормозного крана, интерактивности мышью и касанием; работа в `cab-development`, регулярные checkpoint.
5. **Пассажиры, 28–30 октября 2026.** Полная замена условных фигурок, разнообразие людей, группы, посадка/высадка, анимации движения и поручни. Последний этап ТЗ №4 — толпа 80–100 на платформе, изменяющаяся заполненность четырёх вагонов, полная высадка на конечной. Итоговый SHA `78fd59ae0`, архивная ветка `archive/passengers-tz4-complete-20261030`.
6. **«Малиновка», 30 октября 2026.** ТЗ №1: референсы и концепция Station Base, коммит `77a24a259b`. ТЗ №1.1: измерение реальных mesh v106, аудит колёс/рельсов/порога, коммит `909def5c`. ТЗ №1.2 передано Work на окончательный геометрический стандарт; на момент передачи это **исследование**, а не построение станции.
7. **30 октября 2026.** Создание отдельного архива истории разработки для последующих чатов.
