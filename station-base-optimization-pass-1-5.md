# Station Base — единый прогон оптимизации 1–5 (2026-10-30)

## 1. Диагностика
- Сохранены `window.metroSceneResourceAudit` и `window.metroRenderPassAudit`: уникальные геометрии/материалы/текстуры, топ мешей, реальные счётчики WebGL по 4 проходам.
- Добавлен `window.metroBenchmarkSnapshot()` с ресурсами, проходами, LOD, загрузкой, ошибками и состоянием WebGL.
- Новые GPU-замеры не получены: в этой сессии нет запущенного браузера с WebGL.

## 2. Адаптивная графика
- Добавлен чистый контроллер `AdaptiveQuality.js`: ограниченный DPR, гистерезис FPS, 12-секундное окно, 15-секундный cooldown.
- Активируется **только** в явном тестовом режиме `?quality=low&benchmark=1` (или medium/high), отключается `&adaptive=0`.
- Без `benchmark=1` сохранена прежняя перерисовка по необходимости с ограничением 20 FPS; измеренный FPS этого режима нельзя использовать для автоматической настройки.
- В тестовом режиме непрерывная перерисовка, ограничение 30 FPS для low и 60 FPS для medium/high. Внутреннее разрешение корректируется в пределах DPR 0.55…профильного потолка. Это **экспериментальная адаптация**, не измерение реального GPU времени.

## 3. Геометрия и draw calls
- Существующие оптимизации: shared BoxGeometry станции, InstancedMesh шпал/маркеров, исходный detail culling и дальний proxy v106.
- **Новых объединений мешей поезда и подтверждённого снижения draw calls в этом прогоне нет.** Без фактического профиля по проходам это риск нарушить подвижные двери и световые слои.
- Четыре исходных прохода сохранены.

## 4. Память
- Сохранено однократное преобразование атрибутов на уникальную BufferGeometry в `V106GeometryLoader`, разделение immutable геометрий двух поездов.
- Исправлена консистентность счётчика уникальных текстур/материалов в инвентаризации.
- Не изменён жизненный цикл iframe и PMREM: без визуальной проверки их освобождение может повредить текстуры.

## 5. Тесты
- Добавлен `tests/station-adaptive-quality.test.js` для профилей и контроллера.
- Локальный/CI запуск тестов **не подтверждён**; проверка Playwright/WebGL не проводилась.
- Для запуска вручную: `npm test`, затем `station-base.html?quality=low&benchmark=1`, сравнить с `quality=medium` и `quality=high`, вызвать `metroBenchmarkSnapshot()`.

## Ограничения и приёмка
- Ни 30 FPS на бюджетном смартфоне, ни 45–60 на среднем, ни 60 на флагмане не подтверждены.
- Изменения изолированы в `feature/mobile-render-diagnostics`, без слияний.
- Перед переносом в другие ветки обязательны WebGL smoke, двери, LOD, цвет поезда, память при повторной смене станции, проверка тестов и снимки.
