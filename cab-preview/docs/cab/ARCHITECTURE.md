# Кабина cab-r1: архитектура и связь с игрой

Основной вход остаётся `index.html` → `js/main.js`. Инспектор открывает ту же игру
в iframe; отдельной демонстрационной сцены или имитации физики нет.

| Модуль `js/cab/` | Ответственность |
|---|---|
| `CabModel.js` | Сборка, обновление, зеркала, измерительные точки |
| `CabShell.js` | Три лобовых окна с настоящими проёмами, двери/боковины, пол, потолок, сиденье |
| `CabDesk.js` | Фасонный пульт с вырезом, съёмные панели, приборный блок |
| `CabEquipment.js` | Радиоблок, трубка/шнур, видеомонитор, дворники, вспомогательный пульт |
| `CabInstruments.js` | Корпуса/ободки/шкалы/стрелки/стёкла, сегменты скорости, сигнальные лампы |
| `CabControls.js` | Кнопки с выпуклыми колпачками, селекторы, контроллер и тормозной кран |
| `CabGeometry.js`, `CabMaterials.js` | Общая геометрия, материалы, атлас надписей |
| `CabLighting.js`, `CabBatching.js` | Окружение только материалов кабины, объединение неподвижных деталей |
| `CabCommands.js` | Единые команды для 3D, клавиатуры и экранного управления |
| `CabInteraction.js` | Raycast с проверкой перекрытия, touch, рукоятки, подсказки |

Габариты заданы в метрах кабины, затем переведены в исторические единицы игры
масштабом 1.65. Глаз: `(0, 3.35, 4.72)` в координатах игры; внутреннее положение
остаётся неподвижным при осмотре. Повороты ограничены ±1.04 рад по горизонтали,
−0.68…0.35 рад по вертикали; FOV 38…82°. При повороте меняется перспектива всех
предметов. Камера не перемещается через стенки.

`TrainPhysics.js`, `TrainDoors.js`, пассажиры и станции сохранены без изменений.
Контроллер и тормозной кран управляют существующим `lever`, а двери вызывают
существующий `setCabDoors` с ограничениями скорости, остановки, INFO и штрафов.
Дверные лампы учитывают реальное смещение анимированных створок, а не только
последнюю команду. Независимых левой и правой дверных магистралей в игре нет.

Неподвижные детали объединяются по материалу; динамические рукоятки, колпачки,
селекторы и дворники остаются отдельными. Один атлас 2048² обслуживает надписи.
Зеркала обновляются поочерёдно, одно на три кадра. Кэш теней обновляется при
изменении положения подвижных деталей. Видеомонитор использует существующую
живую заднюю камеру и не добавляет ещё один проход рендера.

| ПРОВЕРКА / СБРОС | Удерживаемая проверка всех ламп/сегментов; T | Подключены |

| кВ / кА | Электрические данные отсутствуют | **НЕТ ДАННЫХ**, стрелки припаркованы, показания не выдумываются |
| КРАН 1/2, ЭПТ | Нет модели давлений/отдельного ЭПТ | Не подключены; подсказка в 3D |
| КОНТРОЛЬ/АРС, АВТОМАТ, РЕЗЕРВ, ПЕСОК, ОБОГРЕВ, БЛОКИРОВКА, остальные радиоклавиши | Соответствующих систем в игре нет | Не подключены; подсказка в 3D |
| Реверс | Физика исходной игры движется только вперёд | Не реализован; ложный действующий переключатель не добавлен |

Неоднозначности AI-эталона разрешены явно: устранены повторяющиеся значения
шкал; ступени тяги возрастают от нейтрали к максимуму; вместо вымышленных
раздельных дверных сигналов указаны действительные состояния общей системы.

## Проверки

`npm run check` — синтаксис и модульные проверки, включая неизменность SHA-256
исходной физики. Старые тесты мгновенного открытия дверей заменены проверкой
плавного движения за 1.55 с; ожидание выбега приведено к существующей формуле
сопротивления. Формулы и игровая динамика при этом не менялись.

`node tests/cab-browser.mjs` — Chromium, настоящие мышь/клавиатура/CDP-touch,
двери/движение/тормоз/камеры/свет/смартфон/запуск, PNG и JSON-отчёт.

`node tests/cab-visual-compare.mjs` — фиксированный ракурс 1536×864, 14 точек
эталона, попарный кадр/наложение и проверка видимых пикселей сегментов скорости.
Порог расположения не является оценкой фотореализма: кадры дополнительно
рассматриваются вручную. Эталон сохраняется побайтно с проверкой хеша.
